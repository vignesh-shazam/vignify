# Glassy Theme

A premium glassmorphism mobile theme for Vignify with frosted glass effects.

## Features

- **Glassmorphism UI**: Frosted glass effects with blur and transparency
- **Botanical Backgrounds**: Natural, calming green foliage backgrounds
- **Dark Mode**: Optimized dark theme with high contrast
- **Glossy Icons**: Custom app icons with 3D glossy effect
- **Smooth Animations**: Premium transitions and hover effects

## Color Palette

- **Primary**: #8B2CFF (Purple)
- **Secondary**: #176DFF (Blue)
- **Accent**: #F000E8 (Pink/Magenta)
- **Background**: #0a0a0f (Dark)
- **Surface**: rgba(255, 255, 255, 0.1)

## Components

### Glass Card
Translucent card with blur effect for modular UI elements.

### Glass Button
Clickable elements with glass effect and hover states.

### Glass Icon
App icons with glossy gradient and glassmorphism.

## Installation

```bash
# Copy theme to your project
cp -r vignify/themes/glassy /path/to/your/project/themes/
```

## Usage

Import the theme CSS in your application:

```css
@import './themes/glassy/styles.css';
```

Apply glass classes to your components:

```jsx
<div className="glass-card">
  <h2>Glass Card</h2>
</div>
```

## Customization

Edit `theme.json` to customize colors and component styles.

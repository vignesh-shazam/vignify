# MIUI Theme Assets for Redmi Note 10 Pro

## Overview
This package contains glassy theme assets compatible with MI Theme Studio for creating `.mtz` themes for Redmi Note 10 Pro.

## Resolution Requirements for Redmi Note 10 Pro
- **Wallpapers**: 2340 x 1080 (Full HD+) or higher
- **Lock Screen**: 2340 x 1080
- **Icons**: Adaptive icons (108 x 108 and 192 x 192)
- **Always-on Display**: 1080 x 2340 (portrait)

## Included Assets

### Wallpapers (6 variations)
- Glassy Purple - Main gradient theme
- Glassy Blue - Blue glass effect
- Glassy Pink - Pink/magenta theme
- Glassy Cyan - Cyan/teal theme
- Glassy Dark - Dark mode variant
- Glassy Botanical - Green foliage theme

### Icons (20 icons)
- Glassy style icon pack with blur effects
- Sizes: 108x108 and 192x192

### Lock Screen (3 variants)
- Glassy lock screen with clock
- Glassy lock screen with widgets
- Glassy lock screen minimal

## How to Use in MI Theme Studio

1. Download MI Theme Studio from Xiaomi
2. Import these assets into your theme project
3. Package as `.mtz` file
4. Transfer to Redmi Note 10 Pro
5. Apply in Settings → Themes

## Color Palette
- Primary: #8B2CFF (Purple)
- Secondary: #176DFF (Blue)
- Accent: #F000E8 (Pink/Magenta)
- Background: #0a0a0f (Dark)
- Surface: rgba(255, 255, 255, 0.1)

- Glassmorphism effects
- Blur and transparency
- Gradient backgrounds
